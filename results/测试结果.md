# 测试结果

模型：基线 U-Net（BCE+Dice）与注意力 U-Net（Tversky），权重在 `outputs_fives/*/checkpoints/best.pth`（服务器 `~/fives/outputs/`）。

测试集：**800 个 512×512 测试块**（来自 200 张测试全图，官方划分，训练过程完全不可见）。评估代码 `src/evaluate.py`，指标只在视野内逐块计算。

## 1. 分割指标

| 指标 | 基线 U-Net | 注意力 U-Net（Tversky） |
|---|---|---|
| Dice | **0.8713** ± 0.140 | 0.8575 ± 0.135 |
| IoU | **0.7904** ± 0.153 | 0.7676 ± 0.146 |
| 敏感性 SE | 0.8602 ± 0.156 | **0.8957** ± 0.150 |
| 特异性 SP | **0.9912** ± 0.006 | 0.9833 ± 0.009 |
| 准确率 Acc | **0.9824** ± 0.009 | 0.9783 ± 0.010 |
| AUC | **0.9900** ± 0.023 | 0.9708 ± 0.047 |

## 4. 复现命令（在服务器上，数据与环境所在处）

```bash
# 登录训练服务器（地址与账号见项目组内部说明），进入项目目录
cd ~/fives
python3 src/evaluate.py --data-root data/FIVES/processed --weights outputs/unet_bce_dice/checkpoints/best.pth
python3 src/evaluate.py --data-root data/FIVES/processed --weights outputs/attn_unet_tversky/checkpoints/best.pth
python3 src/morphology_batch.py --sources 金标准=data/FIVES/processed/test/masks \
    基线U-Net=outputs/unet_bce_dice/predictions/test 注意力U-Net=outputs/attn_unet_tversky/predictions/test \
    --fov-dir data/FIVES/processed/test/fov --out-dir outputs/morphology
```
